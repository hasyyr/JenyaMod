ПРОВЕРКА СБОРКИ И ЗАПУСКА — ЭТАП 11
===================================
1. Открой корневую папку проекта в IntelliJ IDEA Community.
2. Проверь, что Gradle JVM = JDK 21.
3. Дождись Gradle Sync. Если ошибка синхронизации, сохрани полный текст ошибки.
4. В терминале проекта запусти:
   python tools/validate_project.py
   python tools/audit_api_surface.py
5. Затем:
   gradle clean build --stacktrace
6. Если сборка успешна:
   gradle runClient
7. В тестовом мире проверь:
   - мод загружается без crash;
   - сущность Женя появляется через яйцо призыва;
   - модель отображается корректно;
   - idle проигрывается в покое, walk при движении;
   - Женя следует за игроком и останавливается рядом;
   - в latest.log нет ошибок GeckoLib/renderer.
8. Если что-то падает, пришли полный текст ошибки из Gradle или latest.log. Не присылай только последнюю строку.

Не называй проект готовым модом до успешного clean build и runClient.
