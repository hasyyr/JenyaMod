ОБЛАЧНАЯ СБОРКА JENYA С ТЕЛЕФОНА
================================

Что изменено в этом архиве
--------------------------
- Добавлен `.github/workflows/build.yml`: GitHub Actions поднимет Linux runner, установит Java 21 и Gradle 8.14.3, выполнит статические проверки и `gradle clean build`.
- Исправлен ID плагина Fabric Loom на `net.fabricmc.fabric-loom-remap`, который используется для Minecraft 1.21.11 и более старых версий.
- Если сборка пройдёт, JAR появится как artifact в запуске workflow.

Как запустить с телефона
------------------------
1. Создай репозиторий на GitHub. Для первого теста можно сделать его Private.
2. Распакуй этот архив на телефоне.
3. Загрузи СОДЕРЖИМОЕ папки проекта в корень репозитория, включая скрытую папку `.github/workflows/`. Важные файлы: `build.gradle`, `settings.gradle`, `gradle.properties`, `src/`, `tools/`.
   Важно: GitHub web upload может не показать скрытую `.github` папку при обычном выборе файлов. Если так, используй приложение GitHub Mobile вместе с редактором/файловым менеджером, который умеет создавать `.github/workflows/build.yml`, или GitHub Codespaces.
4. Открой вкладку Actions репозитория.
5. Выбери `Build Jenya mod`, нажми `Run workflow`.
6. Дождись окончания. Если зелёный статус — открой запуск и скачай artifact `jenya-fabric-1.21.11`.
7. Если красный статус — открой шаг `Build mod`, скопируй ПЕРВУЮ реальную ошибку компиляции/разрешения зависимости и пришли её сюда.

Безопасность
------------
- Не загружай пароли, токены, ключи, личные данные или игровые аккаунты в репозиторий.
- Для первого прогона Private repository предпочтительнее.
- Artifact доступен из workflow-запуска; это не публикация мода в открытый доступ.
- GitHub Actions — это облачный runner, а не гарантия успеха: проект может выдать реальные ошибки API или зависимостей.
