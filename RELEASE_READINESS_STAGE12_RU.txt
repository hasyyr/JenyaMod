JENYA — RELEASE READINESS REVIEW (STAGE 12)
============================================
Версия цели: Minecraft Java 1.21.11 / Fabric / GeckoLib 5

Что уже присутствует в проекте
------------------------------
- Отдельный ID мода `jenya`.
- Отдельная сущность `JenyaEntity`.
- Геометрия, унаследованная из исходной модели Ellie, и набор анимаций.
- Контроллеры idle/walk.
- Базовая логика следования за игроком.
- Ресурсы предмета яйца призыва.
- Скрипты статической проверки ресурсов и структуры Java-классов.

Что ещё НЕ подтверждено
-----------------------
1. Gradle Sync / разрешение зависимостей.
2. Успешная Java-компиляция против конкретных Yarn mappings и GeckoLib 5.
3. Загрузка в Minecraft через `runClient`.
4. Фактическая регистрация предмета и возможность использовать spawn egg.
5. Правильная UV-развёртка и вид модели в игровом рендерере.
6. Реальная работа навигации/анимаций при движении.

Критические точки проверки
--------------------------
A. Сборка:
   `gradle clean build --stacktrace`
B. Запуск:
   `gradle runClient`
C. В игре:
   - проверить, что мод появляется в списке модов;
   - получить яйцо Жени в творческом инвентаре/через реальную регистрацию предмета;
   - призвать Женю;
   - проверить размер, ориентацию и текстуру;
   - проверить idle/walk;
   - проверить подход и остановку рядом с игроком.
D. При сбое:
   - сохранить полный Gradle stacktrace или `logs/latest.log`;
   - исправлять по первому реальному исключению, а не по последним строкам.

Текущий статус
--------------
Проект остаётся исходным проектом для проверки, а не релизным JAR.
Нельзя объявлять мод готовым, пока не пройдены Gradle build и runClient.
